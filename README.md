# 项目跟进表 — 网页版

一个纯前端的项目跟进管理工具，所有数据保存在浏览器本地，无需后端服务器。

## 功能特点

- **项目总览** — 按公司分组管理项目，显示待办统计
- **日历计划** — 月视图日历，每天可填写计划并标记完成
- **每日跟进** — 记录每天做了什么、遇到什么阻碍、下一步计划
- **待办事项** — P0~P3 优先级管理，截止日期倒计时提醒
- **文件资料** — 每个项目独立管理相关文件（支持上传或记录存放路径）

## 在线使用

通过 GitHub Pages 部署后，直接访问即可使用：

```
https://你的用户名.github.io/project-tracker/
```

## 本地使用

直接下载 `index.html`，用浏览器打开即可。数据保存在浏览器 `localStorage` 中。

## 数据说明

- 项目、跟进记录、待办、日历计划等数据保存在浏览器本地
- 换电脑/换浏览器数据不会同步，建议定期导出备份
- 上传的文件保存在浏览器 `IndexedDB` 中，换设备会丢失
